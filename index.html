تست ارسال Verify

با استفاده از متد /v1/send/verify سامانه SMS.ir

بدون صفر ابتدایی و کد کشور (فقط ۱۰ رقم)
✅ درخواست خود را ارسال کنید تا نتیجه را ببینید.
نکته مهم: قالب شما باید در پنل SMS.ir (بخش ارسال سریع) با شناسه TemplateId و کلید CODE (یا نامی که در پارامتر وارد کرده‌اید) ساخته شده باشد.

🔑 اگر خطای «کلید وب سرویس نامعتبر است» دریافت کردید، کلید API را از پنل SMS.ir (بخش برنامه‌نویسان → کلید وب سرویس) دوباره دریافت کنید.
